Service Changelog

12 Jun 2026: For the main US NEXRAD sites, the file naming was changed to directly replicate what the NWS does on nomads and TGFTP. This means inclusion of seconds in the filename with a bz2 file suffix. Hopefully this doesn't break anybody and of course, you should be using the `dir.list` verbatim anyway for polling.

21 Jan 2026: An archive has been started for the non-NEXRAD RADARs hosted on this site. Please see the per-UTC date data trees within the l2archive directory.
